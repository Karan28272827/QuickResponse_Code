Generic single-database configuration.

### Workflow from now on (typical)
Make model changes in app/models.py (and update any imports).

Create an autogenerated migration:
# ensure PYTHONPATH is set so alembic can import app.models
export PYTHONPATH=.                 # Git Bash
# or in PowerShell: $Env:PYTHONPATH='.'
alembic -c alembic.ini revision --autogenerate -m "describe change"

Review the generated file in alembic/versions/ — ALWAYS inspect and edit it before applying. Autogenerate is helpful, but sometimes it suggests DROP/CREATE for things like server defaults, extensions, or types; clean it up if needed.

Apply the migration:
alembic -c alembic.ini upgrade head

Commit the new migration file(s) and any model changes to git.
